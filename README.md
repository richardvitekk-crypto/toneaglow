# KNEETECH – téma Shopify

Černobílé sportovní téma pro e-shop KNEETECH, postavené na **Dawn 16** od Shopify.

## Propojení se Shopify
Shopify admin → Online obchod → Motivy → Přidat motiv → **Připojit z GitHubu** →
repozitář `toneaglow`, větev `kneetech-theme`.

## Co je navíc oproti Dawn
- `assets/kneetech.css`, `assets/kneetech.js` – vzhled a interakce
- `snippets/kt-logo.liquid` – logo (SVG), `kt-icon.liquid` – ikony
- `snippets/kt-offers.liquid` – výběr balení 1 ks / 2 ks jako karty
- `sections/kt-*.liquid` – vlastní sekce (úvod, výhody, fakta, kroky, srovnání, velikosti, FAQ, videa, plovoucí Koupit)
- `templates/page.size.json`, `page.faq.json`, `page.about.json` – šablony stránek
- Písma Oswald a Inter jsou přímo v tématu (licence OFL, viz `FONTS-OFL-LICENSE.txt`), nic se nenačítá z Googlu.
